# 🪖 HelmVision AI

A real-time helmet detection system built using Deep Learning and Transfer Learning with MobileNetV2. The application can classify whether a rider is wearing a helmet using uploaded images or webcam input through an interactive Streamlit interface.

## 🚀 Live Demo

🔗 https://helmvision-4cappwueobwkyasozehh5uf.streamlit.app/

---

## 📌 Features

- Real-time helmet detection
- Image upload support
- Webcam-based prediction
- Transfer Learning with MobileNetV2
- Interactive Streamlit dashboard
- Fast and lightweight inference

## 📊 Model Performance

| Metric | Score |
|----------|----------|
| Test Accuracy | 89.8% |
| Helmet Precision | 96% |
| Helmet Recall | 89% |
| Helmet F1-Score | 92% |

### Model Comparison

| Model | Test Accuracy |
|---------|---------|
| Custom CNN | 64.3% |
| MobileNetV2 (Transfer Learning) | 89.8% |

Transfer learning with MobileNetV2 improved test accuracy by over **25 percentage points** compared to the custom CNN model.
